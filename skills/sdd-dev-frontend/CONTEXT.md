# SDD-Dev-Frontend

SDD 流程中前端编码阶段的执行上下文。上游交付 `tasks.md` 与设计文档后，本阶段负责把它们变成可验收的前端代码与证据。

Task、Step、AC 锚点、`tasks.md`、`alpha-tests.md` 这些词沿用 SDD-Task 阶段的既有定义，本表不重复。下面只收本阶段独有、或在本阶段被收窄了含义的词。

## Language

### 工作类型

**还原**：
把 HTML 原型的静态呈现落成目标工程组件代码的工作。判据是「没有可断言的行为分支」。
_Avoid_: 切图、设计稿转代码、静态实现

**逻辑补全**：
在已还原的界面结构上接入状态迁移、条件渲染、数据变换与接口交互的工作。判据是「有可断言的行为分支」。
_Avoid_: 联调、功能开发、交互实现

**勘察**：
开工前对规格侧与代码侧既有事实的只读收集。规格侧形成 QA 基线；代码侧只选择 Requirement 决策与仓库范式 ID，不复制仓库事实正文。
_Avoid_: 调研、分析、探索

**检视**：
实现完成后对成果的只读评估，产出分级结论。
_Avoid_: 评审、走查

### 判定与证据

**仓库 baseline**：
由 `sdd-init-frontend` 维护、同仓所有 Requirement/Story 复用的三类事实：`REPO-1` 环境与运行、`REPO-2` 工程质量、`REPO-3` 工程范式。`repo-baseline.md` 是唯一事实源，保存于 SDD 项目的 `frontend-baselines/<repo-id>/`，不写进业务仓。
_Avoid_: 项目 baseline、Story 环境段、本机快照

**工程依据**：
`dev-baseline.md` 中当前 Story 对 `REQ-DEC-*` 与仓库 `PATTERN-*` 的轻量引用，并记录 REPO-3 指纹。它不保存范式正文、源码片段或证据表。
_Avoid_: Story 范式卡片、代码事实副本、`codebase-brief.md`

**需求执行起点**：
`DEMAND-2`。当前 Story 开工时冻结的范围、目标路由、`base-ref`、账号/角色/fixture/API 模式和质量失败集合。它引用仓库 baseline，但与具体起点提交绑定。
_Avoid_: 仓库环境、工程质量能力

**QA 基线**：
`DEMAND-3`。开工前产出、经人工确认后冻结的完成判定标准，分还原侧与功能侧两部分。它回答「怎样算做完」，不描述怎么做。
_Avoid_: 验收标准（那是上游 AC）、测试计划、DoD

**差异清单**：
`restore-report-*.json` 的人类摘要，只列机器报告中的 RED / YELLOW 与补证状态，不再自行判定或复制第二本证据账。
_Avoid_: 视觉 diff、走查记录、问题清单

**还原契约**：
`dev-baseline.md` 中 R1–R6 的 Story 级机器镜像。保存基线内容哈希；基线与契约不一致时拒绝执行。
_Avoid_: 自动验收标准、新基线

**还原报告**：
同一冻结还原契约在 RED / GREEN 阶段执行产生的机器报告。单条状态只有 red、yellow、green；有 RED 即整体 RED，仅 YELLOW 不得判 GREEN。
_Avoid_: 差异清单原文、截图报告

**YELLOW**：
契约规则暂时无法可靠判定，需要明确补证；不是轻微问题，也不是通过。页面不可用、状态 fixture 缺失或机器视觉盲区都可产生 YELLOW。
_Avoid_: 警告、基本通过、待优化

**豁免**：
QA 基线中被显式声明为「允许与原型不一致」的项，每条必须附理由。
_Avoid_: 例外、忽略项

**阻断级**：
检视结论中必须修复才能收口的一类，包括 AC 未覆盖、占位符、类型错误、还原报告存在 RED / YELLOW、测试红、回归破、公共样式硬编码。
_Avoid_: P0、严重

**建议级**：
检视结论中写入报告但不阻断收口的一类。
_Avoid_: P1、次要

**Deferred**：
因外部依赖未就绪而明确推迟、并在 `alpha-tests.md` 中标注的内容。带 Deferred 标记的 AC 不计为已验收。
_Avoid_: 挂起、待办

### 原型

**design tokens**：
设计稿生成器抽出的跨元素共享值。本阶段优先取单属性、被多处引用的共享类；它是设计稿侧事实，不等于目标仓 REPO-3 中的样式/token `PATTERN-*`。
_Avoid_: 设计变量、仓内 token

**Interface Inventory（界面清单）**：
忽略文案、按 `tag + class` 结构签名去重得到的重复模式清单，编号为 `IC-nn`；编号不是组件名，名称与变体关系由 `extract-prototype` 审订。
_Avoid_: 组件清单、组件库

**锚点**：
用于定位原型区块的 class 结构坐标。同名 class 多处出现时带 DOM 序号；根元素无具名 class 时走最近具名祖先／后代的结构路径。格式化档可附行号坐标，行号不作查找手段。
_Avoid_: 行号范围、语义标签

**区块**：
原型页面中一个可命名的视觉单元，是还原工作的最小指派对象，粒度上通常对应一个组件。
_Avoid_: 模块、组件（组件是代码侧概念，区块是原型侧概念）

**区块规格**：
一个区块一份的 Requirement 级设计稿事实，包含锚点、内容哈希、引用组件与 token、逐元素布局值、实例数据及 R1–R6 覆盖。还原轮以它为取值入口，不直接读取原型 HTML。
_Avoid_: 规格卡、原型片段

**设计事实**：
`DEMAND-1` 的机器入口。`design-facts.json` 中由脚本确定性生成的 Requirement 级事实，包含归一化 DOM/CSS、资源内容/缺失状态、区块、结构、静态文案、token 与布局声明。
_Avoid_: QA 基线、还原契约

**原型指纹**：
归一化 DOM/CSS 与外部资源内容/缺失状态共同计算的 SHA-256。只改 HTML 空白格式不变；结构、文案、CSS、资源内容或缺失状态任一变化都会改变。
_Avoid_: `doc_hash`、文件 mtime

**视觉缓存**：
只为 YELLOW 视觉项按需生成的 Requirement 级原型截图缓存；命中只读复用，键失配创建新版本，不覆盖旧版本。
_Avoid_: 实现证据截图、每轮固定截图

**动态数据位**：
设计稿中代表运行时数据的占位符文案。区块规格只保留格式模板，不把样例值作为 R2 文案期望值。
_Avoid_: 假文案、静态标签

**不破**：
上游未定义响应式规格时，本阶段对目标断点承诺的最低保障：无横向滚动、无重叠、无内容截断。不含任何布局结构变化。
_Avoid_: 响应式适配、移动端支持

### 上游约束

**静态实现模式**：
上游 `requirement-frontend-design.md` 声明的对接模式之一，指不接后端、以静态数据实现界面。它是对接模式的取值，不是工作类型——不可用它指代「还原」。
_Avoid_: 静态实现、mock 模式、假数据模式
