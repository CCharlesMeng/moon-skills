## 规范

#### `PATTERN-ROUTE-1` · 无路由机制，单点挂载

| 项 | 内容 |
| --- | --- |
| 规则 | **本仓没有路由库，也没有路由表、守卫、布局容器与代码分割。** 界面全部由 `ROUTE-1` 直接装配，新增面板即在那里挂一个构件。计划期不要引用不存在的路由入口、不要假设有页面级懒加载，也不要为「页面」发明路径参数；首次引入路由属于新规范，须走确认 |
| 依据清单 | `ROUTE-1`、`ROUTE-2` |
| 依据样本 | 依赖里无路由库；`src/main.tsx` 单点挂载到 DOM 根节点，`src/App.tsx` 直接渲染 `PortfolioPanel`，全仓无路径匹配与跳转调用 |
| 违例判定 | 计划或实现引用了不存在的路由表、守卫或布局容器；或以「仓内惯例」为由写出一条路由约定 |
