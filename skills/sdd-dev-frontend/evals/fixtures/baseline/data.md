## 规范

#### `PATTERN-DATA-1` · 异步取数三态与取消

| 项 | 内容 |
| --- | --- |
| 规则 | 组件内取数由以 `use<领域>` 命名的 hook 承载，返回**加载中 / 数据 / 错误**三态；副作用内建取消控制器，卸载时取消。错误必须落到 `error` 字段并由视图渲染错误态，**不得捕获后静默丢弃**；已取消的失败不写入 `error` |
| 依据清单 | `DATA-1`、`API-1` |
| 依据样本 | `src/features/portfolio/usePortfolioSummary.ts`（三态、取消、错误转文案）、`src/features/portfolio/PortfolioPanel.tsx`（视图侧加载 / 错误 / 空三分支渲染） |
| 违例判定 | 取数副作用未建取消控制器或卸载不取消；捕获错误后既不落 `error` 也不提示；视图缺少三分支之一 |
| 验证 | `test` |

#### `PATTERN-DATA-2` · 无缓存层、无全局 store

| 项 | 内容 |
| --- | --- |
| 规则 | **本仓没有取数缓存库，也没有全局 store。** 状态一律留在发起请求的那个组件所在层，靠 props 往下传。计划期不要发明一个仓里没有的 store，也不要假设有请求去重或缓存 |
| 依据清单 | `DATA-1` |
| 依据样本 | 依赖里无取数缓存库与状态管理库；`src/features/portfolio/` 的状态全在 hook 内部 |
| 违例判定 | 计划或实现引用了不存在的 store 或缓存入口 |

#### `PATTERN-DATA-3` · 无表单机制

| 项 | 内容 |
| --- | --- |
| 规则 | **本仓当前没有表单。** 没有表单库、没有集中的校验 schema、没有既成的校验时机约定。首次引入表单属于新规范，须走确认，不得就地发明后当成仓内惯例 |
| 依据清单 | — |
| 依据样本 | 全仓无表单元素、无校验库依赖 |
| 违例判定 | 以「仓内惯例」为由引用一条不存在的表单约定 |
