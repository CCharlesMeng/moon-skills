## 规范

#### `PATTERN-TEST-1` · 无既有测试，也无定位约定

| 项 | 内容 |
| --- | --- |
| 规则 | **框架已装但仓内一个测试文件都没有。** 因此：没有既成的测试文件位置约定，没有元素定位属性约定，也没有列表行区分约定。首个测试要同时定下这三样，**属于新规范，须走确认**——不要声称在沿用仓内惯例 |
| 依据清单 | `TEST-1` |
| 依据样本 | 全仓无 `*.test.*` / `*.spec.*` 文件，无测试目录，无测试环境配置 |
| 违例判定 | 引用一条不存在的仓内定位约定作为基准；或以「仓内惯例」为由跳过对定位方式的确认 |

**这条直接影响下游门禁：** `test` 命令能跑但零用例，所以「跑通 `test`」不构成任何功能证据。需要证据时必须新写用例。
