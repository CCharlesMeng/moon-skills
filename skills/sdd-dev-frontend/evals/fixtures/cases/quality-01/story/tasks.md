# S5 · 持仓明细表格

## 场景

在控制台首页新增「持仓明细」表格，按地区筛选展示持仓列表。数据来自新接口 `GET /api/holdings?region=<地区>`。最多同时展示 500 条持仓。

本 Story 没有设计稿，上游只给了下面这份文字规格，因此 QA 基线的基线源为 `文字规格`。

## 文字规格

- 表格列：地区、金额、状态。按金额从高到低排序。
- 顶部有地区筛选下拉，切换后重新取数。
- 接口 200 但返回空列表时，表格区域显示「暂无持仓」，不渲染空表格。
- 接口失败时显示错误码映射后的文案。
- 最多同时展示 500 条持仓，无需分页或虚拟化之外的额外约束（此规模是否需要虚拟化留给检视判断）。

## AC

| 锚点 | 内容 |
| --- | --- |
| `AC-5.1` | 打开控制台首页，出现持仓明细表格，含地区筛选下拉 |
| `AC-5.2` | 切换地区筛选后，表格按新地区重新取数并按金额从高到低排序 |
| `AC-5.3` | 接口返回空列表时显示「暂无持仓」，不显示空表格 |
