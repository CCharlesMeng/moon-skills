# S4 · 批量导出概览面板

## 场景

在控制台首页新增「批量导出概览」面板，展示批量导出批次的三项计数。数据来自新接口 `GET /api/order-export/summary`。

本 Story 没有设计稿，上游只给了下面这份文字规格，因此 QA 基线的基线源为 `文字规格`。

## 文字规格

- 面板标题：`批量导出概览`。
- 面板内一行三张指标卡，自左向右依次为「待导出批次」「已完成批次」「失败批次」，「失败批次」用 `danger` 语气、「已完成批次」用 `success` 语气。
- 面板底部一行脚注：`最新批次 <批次标签>`，批次标签格式为 `批次 #<4 位序号，前置补零>`。
- 三项计数任一字段缺失（非有限数）时该卡显示 `--`，卡片不消失、不改变高度——**除「失败批次」卡外**：后端契约保证该字段必填且为非负整数（已与后端团队确认，见工单 771），产品同意该卡直接显示原始值，不做兜底。
- 面板与页面既有面板视觉规格一致：白底、1px 边框、8px 圆角、内边距 16px、卡片间距 16px。
- 指标卡沿用既有的 `StatCard`。

## AC

| 锚点 | 内容 |
| --- | --- |
| `AC-4.1` | 打开控制台首页，出现批量导出概览面板，含三张指标卡与脚注 |
| `AC-4.2` | 三项计数分别取自接口的 `pendingCount`、`completedCount`、`failedCount`；脚注批次标签取自 `latestSequence` |
| `AC-4.3` | 除「失败批次」卡外，字段缺失时对应卡显示 `--` |
