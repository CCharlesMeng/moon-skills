# S3 · 客户风险简报概览面板

## 场景

在控制台首页资产组合概览下方新增「客户风险简报」面板，展示三项风险指标。数据来自新接口 `GET /api/risk-brief/summary`。

本 Story 没有设计稿，上游只给了下面这份文字规格，因此 QA 基线的基线源为 `文字规格`。

## 文字规格

- 面板标题：`<租户名> · 客户风险简报`，租户名由父组件传入。
- 面板内一行三张指标卡，自左向右依次为「高风险客户」「风险敞口」「预警命中率」。
- 面板底部一行脚注：`数据每日 06:00 刷新`。
- 面板与页面既有的资产组合概览面板视觉规格一致：白底、1px 边框、8px 圆角、内边距 16px、卡片间距 16px。
- 指标卡沿用既有的 `StatCard`，「高风险客户」用 `danger` 语气。

## AC

| 锚点 | 内容 |
| --- | --- |
| `AC-3.1` | 打开控制台首页，资产组合概览下方出现客户风险简报面板，含三张指标卡与脚注 |
| `AC-3.2` | 三项指标分别取自接口的 `highRiskCount`、`exposure`、`hitRatio`，其中风险敞口按万元展示、预警命中率按一位小数百分比展示 |
| `AC-3.3` | 接口失败时面板内显示错误文案，页面其余部分不受影响 |
