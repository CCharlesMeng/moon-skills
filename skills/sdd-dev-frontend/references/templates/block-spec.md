# 区块规格模板

一个文件只写一个区块。正文不得超过 **12,000 字符**；超过说明切分粒度不合格，退回 `extract-prototype` 重切，不得拆成同一区块的 `part-1` / `part-2`。

```markdown
# 区块规格：<区块名>

| 项 | 值 |
| --- | --- |
| 页面 / 路由 | `<页面名>` / `<路由；未见则写“未见”>` |
| 锚点 | `<逐字复制区块切片的锚点>` |
| 行号坐标 | `<格式化档写 L起–L止；单行档写“-（行号失效）”>` |
| 内容哈希 | `<逐字复制区块切片的 8 位哈希>` |
| 原型指纹 | `<逐字复制 design-facts.json 的 prototype_fingerprint>` |
| 设计事实出处 | `<design-facts.json 的 block anchor / content_hash>` |
| 视觉职责 | `<一个名词短语说清>` |
| 规格时间 | `<YYYY-MM-DD>` |

## 引用组件

| 编号 | 审订名称 | 本区块实例 | 使用方式 / 变体 |
| --- | --- | --- | --- |
| `IC-01` | `<取自 Interface Inventory 的审订名称>` | `<数量>` | `<默认 / 变体名；没有则写“默认”>` |

没有可引用组件时保留标题并写「无」；不得自造 `IC-nn`。

## 引用 design tokens

| Token 类 | 属性 | 值 | 本区块用途 |
| --- | --- | --- | --- |
| `<设计稿侧 token 类>` | `<属性>` | `<值>` | `<对应元素 / 作用>` |

只写设计稿侧 token 类与取值。**禁止出现仓内 `PATTERN-*`**；仓内映射留给实现阶段。

## 逐元素布局值

| 元素 / 具名 class | 层级与职责 | 尺寸 | 间距 | 布局 / 定位 | 视觉值 | 资源 |
| --- | --- | --- | --- | --- | --- | --- |
| `<元素>` / `<.class>` | `<父子关系与职责>` | `<width / height；未见写“未见”>` | `<margin / padding / gap；未见写“未见”>` | `<display / flex / position 等>` | `<颜色 / 字号 / 圆角 / 阴影等>` | `<资源路径与存在/缺失状态；无则写“无”>` |

合并完全相同的重复实例并写 `×N`，不得为了省字丢掉变体差异。CSS 未给出的值写「未见」，不得按浏览器默认值或经验补齐。

| --- | --- |

### 动态数据位

| 位置 | 格式模板 | 格式约束 / 字段语义 |
| --- | --- | --- |

## 资源与降级

| 资源 | 状态 | 影响 |
| --- | --- | --- |

没有资源时保留标题并写「无」。

## R1–R6 覆盖

| 维度 | 状态 | 可判定规格 |
| --- | --- | --- |
| R1 层级 | 已见 / 未见 / 不适用 | `<结构、顺序、数量、显隐>` |

| R3 间距与尺寸 | 已见 / 未见 / 不适用 | `<具体值与对应元素>` |
| R4 状态样式 | 已见 / **未见** / 不适用 | `<静态设计稿没有 hover/focus/disabled/loading 时必须写“未见”，不得推断>` |
| R5 空态 | 已见 / **未见** / 不适用 | `<静态设计稿没有空态时必须写“未见”，不得推断>` |
| R6 目标视口 | 已见 / 未见 / 不适用 | `<只有输入明确给出时才写具体视口；否则写“未见”>` |

## 取证自检

- [ ] 一个文件只含一个区块，正文不超过 12,000 字符
- [ ] 锚点、行号坐标、内容哈希与区块切片逐字一致
- [ ] 原型指纹与设计事实出处可在 `design-facts.json` 中确定性定位
- [ ] `IC-nn` 全部能在 Interface Inventory 找到，没有自造编号
- [ ] token 全部来自设计稿侧，全文没有仓内 `PATTERN-*`
- [ ] 逐元素布局值覆盖区块切片里的具名 class，重复项已合并但变体未丢
- [ ] 静态标签与动态数据位已分开；动态数据位只给格式模板
- [ ] R1–R6 六行齐全；读不到的写「未见」，没有推断
- [ ] 资源缺失的影响已登记
```
