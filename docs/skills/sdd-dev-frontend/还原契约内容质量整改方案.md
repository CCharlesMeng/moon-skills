# 还原契约整改方案：做减法

## Summary

对 `DataDashboard-sdd/requirements/ioc-operation-map-restore` 下 6 个 Story、301 条冻结还原规则、15 份报告做了内容审计。**所有契约都通过 `validate`**，但格式合法掩盖了一批让「契约全绿 ≠ 基线满足」的内容问题，且同一批问题在每个 Story 以不同形态复现。

第一版方案给出 26 项改动，其中 10 项是新增校验。按 `refine-skill` 六条判据回看，那是「默认往上加」的错误方向：现场的错大多是 **schema 太紧逼出来的假值**，而不是太松放任的瞎猜。本版方案改为做减法——删字段、删校验、删子系统、删流程步——只保留让「契约全绿 = 基线满足」成立的最小充分集，其余交给本来就存在的两个人工点（A2 确认门、`acceptance.md`）。

本文四部分：审计结果 → 根因 → 减法方案 → 改造后的 skill 文件结构与产物结构。审计脚本见附录 A。

### 1.4 两处我判错的

- **R1「退化成纯计数」不是问题。** `count` 配精确 locator，加 `order` / `text` 采可访问名与文案，已是基线行诚实的机器镜像；基线行本身仍是人读的完整期望。为此加 `outline` 采集器是在为不存在的缺口加功能。
- **`padding` 简写不是缺陷。** Chrome 对 `padding` 的计算样式返回四值序列化，那 6 条规则跑得好好的。只有 `background` / `flex` 这类带多余分量的简写不可用。

## 二、根因

### 2.1 被反驳的一条假设

**「契约 JSON 要自足」**——自带出处（`design_fact_source`）、自带多层判据（`required_layers` + 分层 `expected` + `static_check`）、自带场景描述（`state_scenario`）、自带防篡改（`contract_sha256` 自哈希）。

它让镜像比原件还厚，而每一处比原件多出来的东西都是失同步的起点。镜像该做的只有一件事：把基线行里机器能判的那部分变成可执行的判据。出处在基线行、场景在基线行、防篡改靠确认门和 RED 相。

### 2.2 逐项归因

| 现场问题 | 太紧 / 太松 | 被反驳的具体假设 |
| --- | --- | --- |
| 假 `expected`、死 `expected.static`、`expected: true` | **太紧**：schema 逼 agent 填没人读的东西 | 「一条规则可以同时要求多层证据」 |
| `design_fact_source` 解析不到、循环引用 | **重复数据必然失同步** | 「机器镜像要自带出处」 |
| R3 static 层被 100% 规避 | **太紧**：按维度给默认层，但 static 有没有意义取决于仓库有没有 token | 「R3 天然该查源码」 |
| 一对多拆分混乱、17→6 覆盖缺口 | **太紧的那句是错的**：recon-spec「R1–R6 每条基线编号恰好出现一次」，而编译器允许一对多 | 「一条基线行 = 一条规则」 |
| `state_scenario` 自造键 | **信息不足，但不该补 schema**：机器只读 `fixture_required`，其余是给驾驭浏览器的人看的备注 | 「`state_scenario` 是机器字段」 |
| count 0 → error | bug | — |
| CSS-only locator | **装饰**：dashboard 的 div 没有可访问名，优先级表没人能遵守 | 「role/name 优先」 |
| visual 子系统 0 使用、tool-equivalence 0 触发、自哈希、adapter 禁字段扫描、locator 排序 | **为「万一」预付** | 「机器能防的都该防」 |

### 2.3 第一版方案为什么是错的方向

第一版对每个问题的回答都是「再定一条语法、再加一道校验」（`design_fact_source` 三个子字段各一道、`state_scenario` schema、弱针正则、简写拒绝、`lint` 子命令、stale 检测）。这会把 6 份契约全部推回重编译，让 `verify_restore_contract.py` 从 1419 行涨到 1800 行，而它防的东西——期望值抄自实现——由 RED 相和「recon-spec 不读实现」两条纪律已经守住了。校验器不拦的东西，文档写多少遍都会再漏，这句话是对的；但反过来，**已经有别的机制在拦的东西，再加一道校验只是收费**。

## 三、减法方案

判定只有四种：**删**、**合并**、**交人工**、**保留**。

### 3.1 契约 schema（v3）

一条规则只属于一层，层由字段推出：有 `static_check` 是 static 规则，否则是 render 规则。

| 字段 | 处置 | 理由 |
| --- | --- | --- |
| `required_layers` | **删** | 由字段推出 |
| 分层 `expected`（`{static, render, visual}`） | **删**：`expected` 只在 render 规则出现，就是比对值 | 假值、死数据的来源 |
| `expected`（overflow / overlap / clip / stacking 除外） | render 规则必填 | 自动变绿的唯一防线 |
| `design_fact_source` | **删** | 出处在基线行「取证方式」列；报告只引 `baseline_id` |
| `dimension` | **删** | `baseline_id` 前缀可推 |
| `block` | **删** | 基线行「判定对象」列已有 |
| `state_scenario` | **改名 `scenario`，自由字符串** | 人读备注；机器只读 `fixture_required`（保留为顶层布尔） |
| `tolerance` | **可选** | 偏离默认时才写 |
| `visual_blind_spot` | **删** | 随 visual 层一起 |
| `check_mode: structure` / `state` / `color` | **并入 `exact` / `numeric`** | 判定逻辑本就相同（`color` 由 `numeric` 的 CSS 等价覆盖） |
| `baseline.path` + `--baseline-ref` | **删** | 文档自己承认「校验时真正读的仍是 `--baseline`」 |
| `contract_sha256` | **保留作链接键，删掉自哈希拒绝** | 基线没变时重编译免费，自哈希防不了手改 |

删完后：render 规则 6 个字段（`id` `baseline_id` `subject` `check_mode` `expected` `scenario`），static 规则把 `check_mode` / `expected` 换成 `static_check`。

`id` 约定一句话：以 `baseline_id` 开头，后接小写连字符 slug；一条基线行的每个独立可判事实各一条规则。不加校验。

### 3.2 校验器（`verify_restore_contract.py`）

| 校验 | 处置 | 删了会漏什么 |
| --- | --- | --- |
| 基线 SHA-256 与契约一致 | 保留 | 改基线不走确认门 |
| `baseline_id` 存在 + 每条基线行被覆盖 + `id` 唯一 | 保留 | 契约全绿 ≠ 基线满足 |
| render 规则 `expected` 非空 | 保留 | 自动变绿 |
| `--after-reconfirmation` 重编译门 | 保留 | 冻结名存实亡 |
| results 的 `contract_sha256` 与契约一致 | 保留 | 拿旧采集拼新报告 |
| `已冻结 ✅` 字面检查 | 保留 | — |
| `rules != raw_rules`「未规范化」 | **删** | 什么都不漏；只在手改缩进时报错 |
| `contract_sha256` 自哈希拒绝 | **删** | 什么都不漏 |
| adapter 递归扫描「混入判定字段」 | **删** | 6 Story 0 命中；写进去也不会被读 |
| locator 优先级排序 | **删** | 297/301 只写 CSS |
| 随机 class 正则 | **降为 warning** | 一次性 Story 不构成故障 |
| `suspected-tool-equivalence` + 退出码 5 + 硬门禁 16 | **删，交人工** | 0 触发、真实案例漏判。替代：RED 且两侧都是字符串时 entry 加 `hint: "字符串不等，先目视是否序列化差异"` |
| 整个 visual 层与 `visual-results.json` | **删，交人工** | 0 使用；「人看两张图」不需要脚本参与 |
| `evidence-format` 子命令 | **删** | 迁移期工具，无 legacy Story 在跑 |
| `stacking` | 保留代码，文档缩到 5 行 | 真实事故场景，但 35 行文档是权重错配 |
| `font-family` 归一化 | **加一行**：`BlinkMacSystemFont` / `-apple-system` → `system-ui` | 已有枚举补一项 |
| 重编译时旧报告改名 `.stale-<sha8>.json` | **加**（在 `contract --after-reconfirmation` 里） | 在制造 stale 的唯一时刻处理一次 |
| 虚拟列表 `windowed`、closed shadow root、`pseudo`、跨页合并 | 保留 | 真实 DOM 现象 |

估算：1419 → ~700 行；112 → ~60 单测；退出码 {0,2,3,5} → {0,2,3}；子命令 5 → 4（`contract` `validate` `static` `report`）。

### 3.3 采集器（`collect_restore_facts.js`）

| 改动 | 性质 |
| --- | --- |
| `count` 匹配 0 → `{status: "ok", actual: 0}` | 修 bug；「不存在」类事实从此能在 render 层表达 |
| 返回顶层加 `observed: {viewport: {width, height}, route}` | 报告如实记录实际跑在什么视口，比校验声明值有用 |
| 删 `kind: structure` | 含原型 class，对契约恒红；design-facts 侧的 `blocks[].structure` 不动 |
| 按 `static_check` 有无推层，不再读 `required_layers` | 配合 v3；v2 契约兼容读 |

### 3.6 流程

| 步骤 | 处置 | 省下什么 |
| --- | --- | --- |
| A1 `extract-prototype` + N × `extract-block-spec` 子代理 | **默认只跑脚本**，主 agent 读切片头出 `block-index.md`；区块规格按需（区块 > 12k 字符或用户点名） | 6 区块 Story 省 7 次子代理往返 |
| A1 三份 Markdown 清单 | **合并为 `design-inventory.md`**（token + 静态/动态文案 + 重复模式）；删「组件命名审订」 | 一轮子代理 |
| A2 `recon-spec` + `recon-codebase` | 保留 | 买到了隔离上下文（规格侧不读实现、代码侧不读原型） |
| A2 确认门 | 保留，**唯一不可删的人工点** | — |
| A2 规则草稿落 `.work/` 再编译 | `contract --rules -` 接 stdin | 一个与契约完全相同的文件 |
| B 新建页面的 RED 相 | **删** | 一轮 static + 注入 + report |
| B `static` 在无 static 规则时 | `report` 缺 `--static-results` 视为无 static 规则 | 一次调用 |
| C 第 4 步重跑全部冻结区块 | **`code_fingerprint` 相对 green 未变则复用 green** | 一轮浏览器注入、一份 43 KB 文件 |
| C `review-restore` 子代理 | **删**，改为 `aggregate` 内一张「三色 × 维度 → 级别」映射表 | 它买不到隔离、并行或独立视角——输入是三色报告，输出是查表。按 refine-skill 判据五这是「摘要无损的机械比对」，恰恰不该委派 |
| C 其余四个检视角色 | 保留 | 要读代码和页面，是真判断 |
| alpha-tests 手抄 64 位指纹 | **删** | 文件名 + `contract_sha256` 前 8 位 |

### 3.7 交给人的是什么

| 删掉的机器环节 | 人在哪里看、看什么 |
| --- | --- |
| visual 层 + 视觉缓存 | `acceptance.md`「你该知道但不用动」节列出：「以下 N 条为机器盲区（图片裁切 / 叠层观感），请在 <路由> 目视」。验收人本来就要打开页面 |
| `suspected-tool-equivalence` | RED entry 带 `hint`；实现者看一眼两侧值 |
| `design_fact_source` 机器解析 / 自哈希防篡改 | A2 确认门：用户确认的是基线行（含取证方式与锚点）。「期望是否抄自实现」由 RED 相和「recon-spec 不读实现」守住 |
| `review-restore` 的定级判断 | 映射表机械给级别；`acceptance.md` 把 RED 原文摆给人 |

不交给人的五条（机器做比人做便宜且可靠）：基线哈希锁、基线行覆盖、render `expected` 非空、重编译门、results 与契约一致。

规则形态只有三种：

| 形态 | 判据字段 | 层 |
| --- | --- | --- |
| render | `check_mode` + `expected`（overflow / overlap / clip 家族只要 `check_mode`，阈值用 `tolerance` 缺省 1 CSS px） | 浏览器采集 |

## 附录 A：审计脚本

`python3 audit_contracts.py <requirement-dir> [<repo-root>]`。v3 落地后 `design_fact_source_*` 与 `state_scenario_*` 两类自然为零（字段不存在）；`r1_count_only` 与 `adapter_css_only_locator` 保留为信息项，不再视为问题。

```python
#!/usr/bin/env python3
"""审计 restore-contract.json 的内容问题（不是格式问题）。"""
import json
import re
import sys
from pathlib import Path

ROOT = Path(sys.argv[1])
REPO = Path(sys.argv[2]) if len(sys.argv) > 2 else None
STORIES = ROOT / "stories"
BARE_LEN = re.compile(r"^\s*-?\d+(\.\d+)?(px|%|em|rem)?(\s+-?\d+(\.\d+)?(px|%|em|rem)?)*\s*$")
BARE_COLOR = re.compile(r"^\s*(#[0-9a-fA-F]{3,8}|rgba?\([^)]*\))\s*$")
BASELINE_ROW = re.compile(r"^\|\s*`?(R[1-6]-\d+)`?\s*\|")
SCENARIO_KEYS = {"name", "fixture", "fixture_required"}


def load(p):
    return json.loads(p.read_text(encoding="utf-8"))


def resolve_design_fact(story_dir, src):
    path, anchor, key = src.get("path", ""), src.get("anchor", ""), src.get("key", "")
    bases = [story_dir, ROOT] + ([REPO] if REPO else [])
    real = next((b / path for b in bases if (b / path).exists()), None)
    if real is None:
        return False, f"path 不存在: {path}"
    if "dev-baseline.md" in path or path.startswith("stories/"):
        return False, f"path 指向基线/Story 产物（循环引用）: {path}"
    if real.suffix == ".json":
        d = load(real)
        anchors = {b.get("anchor") for b in d.get("blocks", [])}
        ld = d.get("layout_declarations", {}) if isinstance(d.get("layout_declarations"), dict) else {}
        if key.startswith("blocks[]"):
            if anchor in anchors:
                return True, ""
            cls = anchor.lstrip(".")
            if cls in ld:
                return False, f"anchor {anchor} 不在 blocks[]，但在 layout_declarations[{cls!r}]，key 写错"
            return False, f"anchor {anchor} 不在 blocks[]"
        if key.startswith("layout_declarations"):
            cls = key.split(".", 1)[1] if "." in key else anchor.lstrip(".")
            return cls in ld, "" if cls in ld else f"layout_declarations 无 {cls!r}"
        if key in ("static_texts", "design_tokens", "resources", "dom_css", "block-order"):
            return True, ""
        return False, f"未知 key 形态: {key}"
    body = real.read_text(encoding="utf-8", errors="replace")
    ok = anchor in body if anchor else True
    return ok, "" if ok else f"anchor {anchor!r} 在 {path} 中找不到"


def baseline_rows(baseline_path):
    rows = {}
    for line in baseline_path.read_text(encoding="utf-8").splitlines():
        m = BASELINE_ROW.match(line.strip())
        if m:
            rows[m.group(1)] = line
    return rows


def count_numbers(text):
    return len(re.findall(r"\d+(?:\.\d+)?\s*(?:px|%|em|rem|:)", text))


def render_expected(exp):
    return exp.get("render", exp) if isinstance(exp, dict) else exp


def audit_story(story_dir):
    ev = story_dir / "evidence"
    contract_p, adapter_p, baseline_p = ev / "restore-contract.json", ev / "restore-adapter.json", story_dir / "dev-baseline.md"
    if not contract_p.exists():
        return None
    c = load(contract_p)
    a = load(adapter_p) if adapter_p.exists() else {"rules": {}}
    rows = baseline_rows(baseline_p) if baseline_p.exists() else {}
    out = {"story": story_dir.name, "rules": len(c["rules"]), "issues": {}}

    def add(kind, rid, note=""):
        out["issues"].setdefault(kind, []).append(f"{rid}{(' ' + note) if note else ''}")

    for r in c["rules"]:
        rid, exp, mode = r["id"], r.get("expected"), r.get("check_mode")
        layers = r.get("required_layers") or (["static"] if r.get("static_check") else ["render"])
        sc = r.get("static_check") or {}
        entry = a["rules"].get(rid, {})
        collect = entry.get("collect", {})
        render = render_expected(exp)

        if isinstance(exp, dict) and "static" in exp:
            add("dead_expected_static", rid, f"static={exp['static']!r}")
        if "render" not in layers and exp not in (None, {}):
            add("expected_without_render_layer", rid, f"expected={exp!r}")
        if mode in ("overflow", "overlap", "clip") and exp is not None:
            add("dummy_expected_for_overflow_family", rid, f"expected={json.dumps(exp, ensure_ascii=False)}")
        if "static" in layers and sc.get("kind") == "text":
            v = str(sc.get("value", ""))
            if BARE_LEN.match(v) or BARE_COLOR.match(v):
                add("weak_static_needle", rid, f"text={v!r}")
        if r["baseline_id"].startswith("R1") and (isinstance(render, (int, float)) or collect.get("kind") == "count"):
            add("r1_count_only", rid, f"expected={render!r} collect={collect.get('kind')}")
        if "design_fact_source" in r:
            ok, note = resolve_design_fact(story_dir, r["design_fact_source"])
            if not ok:
                add("design_fact_source_unresolvable", rid, note)
        if r["baseline_id"].startswith("R3") and r["baseline_id"] in rows:
            n_base = count_numbers(rows[r["baseline_id"]])
            n_exp = len(render) if isinstance(render, dict) else (sum(len(x) if isinstance(x, dict) else 1 for x in render) if isinstance(render, list) else 0)
            siblings = sum(1 for x in c["rules"] if x["baseline_id"] == r["baseline_id"])
            if siblings == 1 and n_base and n_exp and n_exp * 2 < n_base:
                add("r3_expected_undercovers_baseline", rid, f"基线约{n_base}个数值, 契约{n_exp}个")
        ss = r.get("state_scenario")
        if isinstance(ss, dict):
            if ss.get("name") == rid:
                add("state_scenario_name_is_rule_id", rid)
            extra = set(ss) - SCENARIO_KEYS
            if extra:
                add("state_scenario_unread_keys", rid, f"{sorted(extra)}")
        locs = entry.get("locators", [])
        if locs and all(l.get("strategy") == "css" for l in locs):
            add("adapter_css_only_locator", rid)

    for rp in sorted(ev.glob("restore-report-*.json")):
        if ".stale-" in rp.name:
            continue
        d = load(rp)
        if d.get("contract_sha256") != c["contract_sha256"]:
            add("stale_report", rp.name, f"contract={d.get('contract_sha256', '')[:10]} 当前={c['contract_sha256'][:10]}")
    return out


results = [r for sd in sorted(STORIES.iterdir()) if sd.is_dir() and (r := audit_story(sd))]
for r in results:
    print(f"\n=== {r['story']} (rules={r['rules']}) ===")
    for kind, items in sorted(r["issues"].items()):
        print(f"  [{kind}] {len(items)}")
        for it in items:
            print(f"     - {it}")

print("\n=== 汇总 ===")
totals = {}
for r in results:
    for kind, items in r["issues"].items():
        totals[kind] = totals.get(kind, 0) + len(items)
print(f"stories={len(results)} rules={sum(r['rules'] for r in results)}")
for k, v in sorted(totals.items(), key=lambda x: -x[1]):
    print(f"  {k}: {v}")
```
